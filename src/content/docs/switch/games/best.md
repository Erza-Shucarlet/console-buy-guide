机器买了不知道玩什么，是新手最常卡住的地方。这份清单按类型排，每个类型只推真正值得的那几款，顺带标注适合谁。

:::tip[💡 购买提示]
下面全是一代就能玩的作品，Switch 2 也向下兼容。想省钱就买二手卡带，玩完再出，实际成本往往只有原价三成。
:::

## 🌍 开放世界：任天堂的门面

| 游戏 | 适合谁 | 说明 |
|---|---|---|
| 塞尔达传说 旷野之息 | 第一次接触塞尔达 | 自由度极高，解谜与探索为主，可以玩上百小时 |
| 塞尔达传说 王国之泪 | 玩过旷野之息 | 前作的正统续作，加了建造与天空层，玩法更野 |

这两款常被称作「买 Switch 的理由」，不过也有人嫌节奏慢。建议先看十分钟试玩再决定。

## 🍄 平台动作：最适合解压

| 游戏 | 适合谁 |
|---|---|
| 超级马力欧 奥德赛 | 全年龄，单人为主，收集要素多 |
| 星之卡比 探索发现 | 想放松、带小孩一起玩 |
| 超级马力欧 兄弟 惊奇 | 多人同乐，横版跳跃 |

## 🏎️ 竞速与派对：多人场景刚需

| 游戏 | 场景 |
|---|---|
| 马力欧赛车 8 豪华版 | 全家/朋友聚会第一选择，上手门槛极低 |
| 超级马力欧派对（含超级巨星） | 4 人同屏小游戏，聚会神器 |
| 任天堂明星大乱斗 特别版 | 格斗但好上手，角色阵容夸张 |

## 🎯 射击与竞技

| 游戏 | 说明 |
|---|---|
| 喷射战士 3 | 涂地玩法独特，节奏快，需要联网（要 NSO 会员） |
| 马力欧 + 疯狂兔子 | 战棋 + 幽默演出，单机耐玩 |

## 🏝️ 生活模拟与养成

| 游戏 | 说明 |
|---|---|
| 动物森友会 | 慢节奏、无压力，适合每天 20 分钟 |
| 星露谷物语 | 种田 + 社交 + 探索，性价比极高（独立游戏） |

## ⚔️ RPG 与策略

| 游戏                    | 说明                |
| --------------------- | ----------------- |
| 异度神剑 2                | 剧情向 JRPG，战斗系统复杂但爽 |
| 火焰纹章 风花雪月             | 战棋 + 养成，剧情分支多     |
| 宝可梦 系列（朱/紫、传说 阿尔宙斯 等） | 收集养成，适合轻度玩家       |

## 🕹️ 独立游戏：便宜且耐玩

| 游戏 | 说明 |
|---|---|
| 空洞骑士 | 类银河恶魔城，难度高、氛围极佳 |
| 哈迪斯 | 肉鸽动作，重玩价值极高 |
| 挺进地牢 / 杀戮尖塔 | 单局短、随时拿起来玩 |

## 🎮 怎么买最省

- 单机大作：买二手卡带，玩完出掉，成本最低
- 常玩的联机游戏：数字版更方便，等 eShop 打折入手
- 派对类：卡带更划算，朋友之间还能互相借
