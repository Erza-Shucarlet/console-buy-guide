## 两代核心差异速览

| | Switch 一代 | Switch 二代 |
|------|:----------:|:----------:|
| 发售时间 | 2017~2021 | 2025.06 |
| 最高画质 | 1080p | 4K |
| 屏幕 | LCD / OLED | LCD (120Hz) |
| 存储 | 32/64GB | 256GB |
| Joy-Con | 滑轨插拔 | 磁吸 |
| 起步价 | $299 | $449.99（9月起$499.99） |
| 兼容性 | — | ✅ 兼容一代卡带 |

> 二代兼容几乎所有一代游戏，且大多有更好的表现效果。如果你没有任何 Switch，二代是当下最省心的选择。
